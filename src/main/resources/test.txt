Phím tắt	Chức năng
Super (phím Windows)	Mở menu “Activities” (hiển thị cửa sổ, tìm ứng dụng)
Alt + F2	Mở hộp thoại “Run Command”
Ctrl + Alt + T	Mở Terminal mới
Super + L hoặc Ctrl + Alt + L	Khóa màn hình
Super + D	Hiện/ẩn Desktop (thu nhỏ tất cả cửa sổ)
Alt + Tab	Chuyển đổi giữa các cửa sổ đang mở
Alt + ` (phím ~ trên bàn phím)	Chuyển đổi giữa các cửa sổ của cùng 1 ứng dụng
Super + A	Mở danh sách ứng dụng
Print Screen	Chụp toàn màn hình
Shift + Print Screen	Chụp một vùng màn hình chọn bằng chuột
Alt + Print Screen	Chụp cửa sổ hiện tại
📂 Quản lý cửa sổ
Phím tắt	Chức năng
Super + ↑	Phóng to cửa sổ hiện tại (maximize)
Super + ↓	Thu nhỏ cửa sổ hoặc khôi phục từ phóng to
Super + ←	Ghim cửa sổ sang trái màn hình (tiling)
Super + →	Ghim cửa sổ sang phải màn hình
Alt + F4	Đóng cửa sổ hiện tại
Alt + Space	Mở menu điều khiển cửa sổ (move, resize, minimize)
Ctrl + Alt + Arrow (←,→,↑,↓)	Chuyển sang workspace khác (mặc định có 4 workspace)
Shift + Ctrl + Alt + Arrow	Di chuyển cửa sổ sang workspace khác
📝 Terminal
Phím tắt	Chức năng
Ctrl + Shift + T	Mở tab mới trong Terminal
Ctrl + Shift + W	Đóng tab hiện tại
Ctrl + PageUp / PageDown	Chuyển đổi giữa các tab Terminal
Ctrl + Shift + C	Copy trong Terminal
Ctrl + Shift + V	Paste trong Terminal
Ctrl + C	Dừng tiến trình đang chạy trong Terminal
Ctrl + L	Xóa màn hình Terminal (clear)
Ctrl + D	Đăng xuất khỏi shell hiện tại
Ctrl + R	Tìm kiếm lệnh trong history
📝 Text & Editing (ứng dụng soạn thảo)
Phím tắt	Chức năng
Ctrl + A	Chọn tất cả
Ctrl + X / C / V	Cắt / Copy / Paste
Ctrl + Z	Hoàn tác (Undo)
Ctrl + Shift + Z	Làm lại (Redo)
Ctrl + S	Lưu
Ctrl + Q	Thoát ứng dụng
